# Норман

Кроссплатформенное приложение для первого алгоритмического прохода антикоррупционной экспертизы. Оно показывает возможные сигналы по правилам, цитирует фрагмент документа и оставляет юридическую оценку специалисту. AI-провайдеров в MVP нет.

## Запуск

Нужны Node.js с npm и стабильный Rust toolchain. Для Tauri также нужны системные зависимости текущей ОС: [официальные требования](https://v2.tauri.app/start/prerequisites/).

```sh
npm install
npm run tauri dev
```

Рабочий поток: выбрать файл или вставить HTTP(S)-ссылку → открыть анализ → дождаться совпадений. Обработка файлов и поиск правил выполняются локально. Для сайта приложение отдельно показывает исходную страницу в ограниченном iframe и извлечённый текст, по которому можно перейти к совпадению.

Чтобы пройти полный сценарий в браузере без сборки Tauri, запустите `npm run dev` и откройте `http://127.0.0.1:1420/`. Dev-сервер локально принимает URL и выбранные файлы; обработчики не входят в настольную сборку. Для PDF нужен `pdftotext`, для офисных форматов — LibreOffice/soffice.

## Форматы

- Word: `.doc`, `.dot`, `.docx`, `.docm`, `.dotx`, `.dotm`.
- LibreOffice/OpenDocument: `.odt`.
- PDF с извлекаемым текстом, RTF и обычный текст (`.txt`, `.text`, `.md`, `.csv`).
- `.doc` и `.dot` читаются локальным парсером; при необходимости используется установленный LibreOffice/soffice. Для сканированных PDF OCR пока нет. Парольные, повреждённые, слишком большие и неподдерживаемые файлы завершаются понятной ошибкой.
- Для URL загружается текстовая версия страницы с ограничениями размера, времени и числа перенаправлений. Сценарии страницы не запускаются во встроенном просмотре.

Правила и их обоснования находятся в [data/rules.json](data/rules.json); описание соответствия приложенной методике — в [docs/analysis-method.md](docs/analysis-method.md). Каталог правил пока покрывает только часть методики и выдаёт сигналы, а не юридические заключения.

## Сборки

Цели упаковки заданы в `src-tauri/tauri.conf.json`: NSIS для Windows (`*-setup.exe`), AppImage для Linux и DMG для macOS. Установите [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для своей ОС, затем выполните на целевой ОС:

```sh
npm ci
npm run tauri build -- --bundles dmg      # macOS
npm run tauri build -- --bundles nsis     # Windows
npm run tauri build -- --bundles appimage # Linux
```

GitHub Actions запускает упаковку вручную или при push тега версии `v*`. macOS DMG и Windows NSIS установщик собираются на своих ОС и загружаются как артефакты запуска workflow. GitHub Release не создаётся. Linux AppImage можно собрать локально приведённой командой.

## Просмотр сайта и uBlock Origin

Встроенный просмотр сайта ограничивает навигацию, отключает JavaScript и не даёт удалённой странице доступа к командам приложения. Кнопка открытия оригинала запускает системный браузер, где используется установленный uBlock Origin. Встроенное расширение uBlock нельзя обещать на всех платформах: Tauri поддерживает WebView-расширения в Windows, но не в macOS и Linux ([документация Tauri](https://docs.rs/tauri/latest/tauri/webview/struct.WebviewWindowBuilder.html#method.browser_extensions_enabled)).
