# Норман АЭ

Кроссплатформенное приложение для первичной антикоррупционной экспертизы. Оно сначала локально ищет сигналы по правилам, затем — если пользователь включил AI — просит выбранного провайдера проверить найденное и поискать новые фрагменты. Поддерживаются Codex CLI, Ollama, Cloud.ru Foundation Models и Yandex AI Studio. Юридическую оценку принимает специалист.

## Запуск

Нужны Node.js с npm и стабильный Rust toolchain. Для Tauri также нужны системные зависимости текущей ОС: [официальные требования](https://v2.tauri.app/start/prerequisites/).

```sh
npm install
npm run tauri dev
```

Рабочий поток: выбрать файл или вставить HTTP(S)-ссылку → открыть анализ → дождаться совпадений. Обработка файлов и поиск правил выполняются локально. AI выключен по умолчанию. При выборе Codex требуется установленный и авторизованный Codex CLI; по умолчанию используются GPT-6 Luna и высокий уровень рассуждения. Ollama подключается к выбранному серверу (по умолчанию `http://127.0.0.1:11434`) и позволяет выбрать модель, установленную в нём. Cloud.ru Foundation Models и Yandex AI Studio подключаются через OpenAI-совместимые API, доступные модели загружаются динамически. Для Cloud.ru нужен API-ключ. Для Yandex AI Studio сервисному аккаунту нужна роль `ai.languageModels.user`, а API-ключу — области `yc.ai.models.viewer` и `yc.ai.foundationModels.execute`; приложению также нужен ID каталога. Оба ключа хранятся только в памяти приложения и не записываются в localStorage, конфигурационные файлы или логи; ID каталога Yandex Cloud сохраняется в настройках. Текст документа и найденные сигналы передаются только выбранному провайдеру. Каждый запуск анализа начинается с нуля: ответы AI не кэшируются. Для ссылки приложение показывает сохранённый HTML исходной страницы в ограниченном iframe; извлечённая копия текста в режиме анализа не показывается, а найденный фрагмент подсвечивается в исходном превью.

Чтобы пройти полный сценарий в браузере без сборки Tauri, запустите `npm run dev` и откройте `http://127.0.0.1:1420/`. Dev-сервер локально принимает URL и выбранные файлы; в нём доступен AI-маршрут Codex CLI. Ollama доступна в настольном приложении через Tauri и не подключается из браузерного dev-режима. Dev-маршруты Codex доступны только из локального окна разработки и не входят в настольную сборку. AI-проход ограничен текстом до 512 КиБ, 30 проверками алгоритмических сигналов и 30 новыми AI-находками за один запуск. При достижении лимита AI-этап возвращает ошибку о возможной неполноте результата, без скрытого усечения; локальные алгоритмические результаты остаются доступными. Для PDF нужен `pdftotext`, для офисных форматов — LibreOffice/soffice.

## Форматы

- Word: `.doc`, `.dot`, `.docx`, `.docm`, `.dotx`, `.dotm`.
- LibreOffice/OpenDocument: `.odt`.
- PDF с извлекаемым текстом, RTF и обычный текст (`.txt`, `.text`, `.md`, `.csv`).
- `.doc` и `.dot` читаются локальным парсером; при необходимости используется установленный LibreOffice/soffice. Для сканированных PDF OCR пока нет. Парольные, повреждённые, слишком большие и неподдерживаемые файлы завершаются понятной ошибкой.
- Для URL приложение один раз загружает HTML с ограничениями размера, времени и числа перенаправлений: из него извлекает текст для поиска и показывает исходную страницу из снимка в sandbox iframe. Сценарии страницы, вложенные фреймы и формы отключены; найденный фрагмент можно подсветить прямо в превью.

Правила и их обоснования находятся в [data/rules.json](data/rules.json); описание соответствия приложенной методике — в [docs/analysis-method.md](docs/analysis-method.md). Каталог правил пока покрывает только часть методики и выдаёт сигналы, а не юридические заключения.

## Сборки

Цели упаковки: NSIS для Windows x64 (`*-setup.exe`), AppImage для Linux x64 и универсальный DMG для macOS Intel/Apple Silicon. Установите [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для своей ОС, затем выполните на целевой ОС:

```sh
npm ci
npm run tauri build -- --bundles dmg      # macOS
npm run tauri build -- --bundles nsis     # Windows
npm run tauri build -- --bundles appimage # Linux
```

Для выпуска укажите одинаковую версию в `package.json` и `src-tauri/tauri.conf.json`, проверьте её и отправьте тег:

```sh
npm run release:check -- v1.2.3
git tag v1.2.3
git push origin v1.2.3
```

GitHub Actions соберёт macOS DMG, Windows NSIS и Linux AppImage и приложит файлы к GitHub Release. Повторный запуск обновит файлы релиза. `workflow_dispatch` соберёт те же файлы как артефакты workflow, но не опубликует релиз. Локальную сборку запускайте на целевой ОС приведёнными выше командами; для неё нужны системные зависимости Tauri.

## Просмотр сайта и uBlock Origin

Встроенный просмотр сайта ограничивает навигацию, отключает JavaScript и не даёт удалённой странице доступа к командам приложения. Кнопка открытия оригинала запускает системный браузер, где используется установленный uBlock Origin. Встроенное расширение uBlock нельзя обещать на всех платформах: Tauri поддерживает WebView-расширения в Windows, но не в macOS и Linux ([документация Tauri](https://docs.rs/tauri/latest/tauri/webview/struct.WebviewWindowBuilder.html#method.browser_extensions_enabled)).
